# Hyperbolic functions
Definitions:
- \(\cosh x = \dfrac{e^x+e^{-x}}{2}\) and \(\sinh x = \dfrac{e^x-e^{-x}}{2}\)
- \(\tanh x = \dfrac{\sinh x}{\cosh x}\)

## Identity (a)
Show that **cosh² x − sinh² x = 1**.
Expand both squares with the exponential definitions. The terms e^{2x} and e^{-2x} cancel, and only ¼(2 + 2) = 1 is left. ~~This is wrong~~ This is the hyperbolic version of cos² + sin² = 1.
\[\cosh^2 x-\sinh^2 x=\tfrac14\left[(e^x+e^{-x})^2-(e^x-e^{-x})^2\right]=1\]

## Identity (b)
1. Write tanh(a − b) as sinh(a − b) / cosh(a − b).
2. Use the subtraction formulas.
3. Divide top and bottom by cosh a cosh b.
==Result: tanh(a − b) = (tanh a − tanh b) / (1 − tanh a tanh b)==
